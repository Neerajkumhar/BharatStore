# BharatStore M0+M1 Implementation Plan — Foundations, Auth & Tenant Core

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the monorepo skeleton, the Fastify API with auth + tenant resolution, the Next.js app with design tokens + auth pages + onboarding wizard + app shell, and prove end-to-end that a user can sign up → create a business → log in → land on a tenant-guarded dashboard.

**Architecture:** npm-workspaces monorepo (`apps/web` Next.js, `apps/api` Fastify, `packages/shared` zod+constants, `packages/config` lint/tsconfig). The API owns auth, tenant resolution (JWT claims) and Row-Level-Security isolation; the web app owns the UI and holds the refresh token in an httpOnly cookie behind server actions (BFF). Client→API calls go through a Next.js `/api/*` rewrite so browser origin stays unified in dev.

**Tech Stack:** TypeScript, npm workspaces + Turbo, Next.js 14 (App Router), Tailwind CSS v3 + shadcn/ui primitives, Fastify, Drizzle ORM + postgres-js, PostgreSQL 16, Redis 7 (compose only; consumed from M5), @fastify/jwt (HS256, upgrade path documented), bcrypt, Zod, Vitest, GitHub Actions.

**Master spec:** `docs/superpowers/specs/2026-09-05-bharatstore-blueprint-design.md` (the blueprint). Sections 9–14 are the source of truth for this plan.

**Deviation notes from blueprint (all deliberate, documented):**
- HS256 JWT for M0/M1 (single strong secret) instead of RS256 — strictly simpler for a student team; `lib/jwt.ts` is algorithm-configurable so RS256 is a drop-in later. Blueprint §9.5/§13.2.
- In-memory rate-limit store for M0/M1; Redis-backed store lands in M5 with BullMQ. Blueprint §13.7.
- SendGrid wrapped behind a console fallback when `SENDGRID_API_KEY` is unset — M1 dev runs without keys. Blueprint §9.5.

```ts
import { z } from "zod";

export const emailSchema = z.string().trim().toLowerCase().email("Enter a valid email address");

export const passwordSchema = z
  .string()
  .min(8, "At least 8 characters")
  .regex(/[a-zA-Z]/, "Include at least one letter")
  .regex(/[0-9]/, "Include at least one number");

export const signupSchema = z.object({
  name: z.string().trim().min(2, "Enter your full name"),
  email: emailSchema,
  password: passwordSchema
});
export type SignupInput = z.infer<typeof signupSchema>;

export const loginSchema = z.object({
  email: emailSchema,
  password: z.string().min(1, "Enter your password")
```

```ts
import type { FastifyReply, FastifyRequest } from "fastify";
import { ERROR_STATUS, type APIErrorCode } from "@bharatstore/shared";

export class ApiError extends Error {
  code: APIErrorCode;
  fieldErrors?: Record<string, string[]>;
  statusCode: number;

  constructor(code: APIErrorCode, message: string, fieldErrors?: Record<string, string[]>) {
    super(message);
    this.code = code;
    this.fieldErrors = fieldErrors;
    this.statusCode = ERROR_STATUS[code];
  }
}

export async function errorHandler(
  error: Error & { code?: string; statusCode?: number; validation?: unknown },
  _req: FastifyRequest,
  reply: FastifyReply
) {
  if (error instanceof ApiError) {
    return reply.status(error.statusCode).send({
      success: false,
      error: {
        code: error.code,
        message: error.message,
        fieldErrors: error.fieldErrors
      }
    });
  }

  // Fastify schema validation errors
  if (error.validation) {
    const fieldErrors: Record<string, string[]> = {};
    for (const v of error.validation) {
      const key = String(v.instancePath?.replace("/", "")) || "body";
      fieldErrors[key] = [...(fieldErrors[key] ?? []), v.message ?? "Invalid value"];
    }
    return reply.status(400).send({
      success: false,
      error: { code: "VALIDATION_ERROR", message: "Request validation failed", fieldErrors }
    });
  }

  const status = error.statusCode && error.statusCode < 500 ? error.statusCode : 500;
  if (status >= 500) request.log(error);
  return reply.status(status).send({
    success: false,
    error: { code: status === 404 ? "NOT_FOUND" : "INTERNAL", message: error.message }
  });
}

// pino receives the log object; kept as a tiny wrapper for clarity
function requestLog(err: Error) {
  console.error("[unhandled]", err);
}
```

```ts
type TenantScopeFn<T> = (tx: DBTx) => Promise<T>;

/**
 * Run fn inside a transaction where RLS is scoped to tenantId.
 * set_config(..., true) is LOCAL to the transaction — safe on pooled connections.

export async function tenantTransaction<T>(tenantId: string, fn: TenantScopeFn<T>): Promise<T> {

    await tx.execute(sql`SELECT set_config('app.current_tenant', ${tenantId}, true)`);
    return fn(tx);
  });
}
```

```ts
  "billing.view": "billing", "billing.update": "billing",
  "product.view": "products", "product.create": "products", "product.update": "products", "product.delete": "products",
  "category.manage": "categories",
  "inventory.view": "inventory", "inventory.update": "inventory",
  "order.view": "orders", "order.create": "orders", "order.update": "orders", "order.cancel": "orders",
  "customer.view": "customers", "customer.create": "customers", "customer.update": "customers",
  "payment.view": "payments", "payment.refund": "payments",
  "invoice.view": "invoices", "invoice.create": "invoices", "invoice.send": "invoices",
  "storefront.manage": "storefront",
  "marketing.manage": "marketing",
  "analytics.view": "analytics",
  "staff.manage": "staff", "role.manage": "staff",
  "audit.view": "security", "security.view": "security", "security.settings": "security"
};

// Idempotent: safe to re-run.
for (const code of ROLE_CODES) {
  const role = await db.insert(roles).values({ code, name: code, description: ROLE_DESCRIPTIONS[code] })
    .onConflictDoUpdate({ target: roles.code, set: { description: ROLE_DESCRIPTIONS[code] } })
    .returning();
  const roleId = role[0]!.id;

  const allPerms = await db.select().from(permissions);
  const permByCode = new Map(allPerms.map((p) => [p.code, p.id]));
  const missing = ROLE_PERMISSIONS[code as RoleCode].filter((p) => !permByCode.has(p));
  if (missing.length > 0) {
    await db.insert(permissions).values(
      missing.map((p) => ({ code: p, module: MODULE_BY_PERMISSION[p], description: p }))
    ).onConflictDoNothing();
  }

  const refreshed = await db.select().from(permissions);
  const idsForRole = ROLE_PERMISSIONS[code as RoleCode]
    .map((p) => refreshed.find((r) => r.code === p)?.id)
    .filter((id): id is string => Boolean(id));
  await db
    .insert(rolePermissions)
    .values(idsForRole.map((permissionId) => ({ roleId, permissionId })))
    .onConflictDoNothing();
}
```

```ts
import { and, eq, gt, isNull, sql } from "drizzle-orm";
import { createHash } from "node:crypto";
import type { FastifyBaseLogger, FastifyInstance } from "fastify";
import {
  ApiError
} from "../plugins/error-handler";
import { db } from "../db/client";
import { authTokens, memberships, roles, sessions, users } from "../db/schema";
import { env } from "../config/env";
import { hashPassword, verifyPassword } from "../lib/passwords";
import { createAccessToken, hashToken, issueRefreshToken } from "../lib/jwt";
import { createSession, findSessionByToken, rotateSession, revokeSession } from "../lib/sessions";
import { sendEmail } from "../lib/email";
import type {
  AccessTokenClaims, CreateBusinessInput, CreateStoreInput, LoginResult
} from "@bharatstore/shared";

const REFRESH_TTL_MS = 30 * 24 * 60 * 60 * 1000;   // 30d
const TOKEN_TTL_MS = 60 * 60 * 1000;               // 1h verify/reset

export function issuer(app: FastifyInstance) {
  return {
    provisionUser: (input: { name: string; email: string; password: string }, log: FastifyBaseLogger) =>
      provisionUser(app, input, log),
    login: (input: { email: string; password: string }, meta: { ip?: string; ua?: string }) =>
      login(app, input, meta),
    refresh: (input: { refreshToken: string }, meta: { ip?: string; ua?: string }) =>
      refresh(app, input, meta),
    logout: (refreshToken: string) => logout(app, refreshToken),
    verifyEmail: (rawToken: string) => verifyEmail(app, rawToken),
    forgotPassword: (email: string, log: FastifyBaseLogger) => forgotPassword(app, email, log),
    resetPassword: (rawToken: string, newPassword: string) => resetPassword(app, rawToken, newPassword)
  };
}

async function provisionUser(app: FastifyInstance, input: { name: string; email: string; password: string }, log: FastifyBaseLogger) {
  const existing = await db.query.users.findFirst({ where: eq(users.email, input.email) });
  if (existing) throw new ApiError("CONFLICT", "An account with this email already exists");

  const user = (await db.insert(users).values({
    name: input.name,
    email: input.email,
    passwordHash: await hashPassword(input.password),
    status: "unverified"
  }).returning())[0]!;

  const token = issueRefreshToken(); // reused as a raw 96-hex token for verification links
  await db.insert(authTokens).values({
    userId: user.id,
    type: "email_verification",
    tokenHash: hashToken(token),
    expiresAt: new Date(Date.now() + TOKEN_TTL_MS)
  });
  await sendEmail({
    to: user.email,
    subject: "Verify your BharatStore account",
    text: `Verify your email: ${env.FRONTEND_URL}/verify-email?token=${token}`
  });
  log.info({ userId: user.id }, "user provisioned");
  return { id: user.id, email: user.email, name: user.name };
}

async function login(app: FastifyInstance, input: { email: string; password: string }, meta: { ip?: string; ua?: string }): Promise<LoginResult> {
  const user = await db.query.users.findFirst({ where: eq(users.email, input.email) });
  if (!user) throw new ApiError("AUTH_INVALID_CREDENTIALS", "Incorrect email or password");
  if (user.status === "suspended") throw new ApiError("AUTH_LOCKED", "This account is suspended");
  if (!(await verifyPassword(input.password, user.passwordHash)))
    throw new ApiError("AUTH_INVALID_CREDENTIALS", "Incorrect email or password");

  const membership = await activeMembership(user.id);

  const claims = buildClaims(user.id, user.email, membership);
  const config = tokenConfig();
  return finishLogin(app, user, membership, claims, config, meta);
}

async function refresh(app: FastifyInstance, input: { refreshToken: string }, meta: { ip?: string; ua?: string }) {
  const existing = await findSessionByToken(input.refreshToken);
  if (!existing) throw new ApiError("TOKEN_INVALID", "Session not found");
  if (existing.replacedById) {
    // Reuse detection: revoke whole family
    await db.update(sessions).set({ revokedAt: new Date() }).where(eq(sessions.id, existing.id));
    throw new ApiError("TOKEN_INVALID", "Session reused — revoked family");
  }
  const user = await db.query.users.findFirst({ where: eq(users.id, existing.userId) });
  if (!user || user.status === "suspended") throw new ApiError("TOKEN_INVALID", "Account unavailable");

  await rotateSession(existing.id, issueRefreshToken(), REFRESH_TTL_MS);

  const membership = existing.businessId
    ? (await db.query.memberships.findFirst({
        where: and(eq(memberships.businessId, existing.businessId), eq(memberships.userId, user.id), eq(memberships.status, "active"))
      }) ?? (await activeMembership(user.id)))
    : await activeMembership(user.id);

  const claims = buildClaims(user.id, user.email, membership);
  const config = tokenConfig();
  return finishLogin(app, user, membership, claims, config, meta);
}

async function logout(app: FastifyInstance, refreshToken: string) {
  const existing = await findSessionByToken(refreshToken);
  if (existing) await revokeSession(existing.id);
}

async function verifyEmail(app: FastifyInstance, rawToken: string) {
  const found = await db.query.authTokens.findFirst({
    where: and(
      eq(authTokens.type, "email_verification"),
      eq(authTokens.tokenHash, hashToken(rawToken)),
      isNull(authTokens.usedAt),
      gt(authTokens.expiresAt, sql`now()`)
    )
  });
  if (!found) throw new ApiError("TOKEN_INVALID", "Verification link is invalid or expired");
  await db.transaction(async (tx) => {
    await tx.update(authTokens).set({ usedAt: new Date() }).where(eq(authTokens.id, found.id));
    await tx.update(users).set({ status: "active" }).where(eq(users.id, found.userId));
  });
}

async function forgotPassword(app: FastifyInstance, email: string, log: FastifyBaseLogger) {
  const user = await db.query.users.findFirst({ where: eq(users.email, email) });
  if (!user) return; // do not reveal account existence
  const token = issueRefreshToken();
  await db.insert(authTokens).values({
    userId: user.id,
    type: "password_reset",
    tokenHash: hashToken(token),
    expiresAt: new Date(Date.now() + TOKEN_TTL_MS)
  });
  await sendEmail({
    to: user.email,
    subject: "Reset your BharatStore password",
    text: `Reset your password: ${env.FRONTEND_URL}/reset-password?token=${token}`
  });
  log.info({ userId: user.id }, "password reset requested");
}

async function resetPassword(app: FastifyInstance, rawToken: string, newPassword: string) {
  const found = await db.query.authTokens.findFirst({
    where: and(
      eq(authTokens.type, "password_reset"),
      eq(authTokens.tokenHash, hashToken(rawToken)),
      isNull(authTokens.usedAt),
      gt(authTokens.expiresAt, sql`now()`)
    )
  });
  if (!found) throw new ApiError("TOKEN_INVALID", "Reset link is invalid or expired");
  await db.transaction(async (tx) => {
    await tx.update(authTokens).set({ usedAt: new Date() }).where(eq(authTokens.id, found.id));
    await tx.update(users).set({ passwordHash: await hashPassword(newPassword) }).where(eq(users.id, found.userId));
  });
}

// ---- shared helpers -------------------------------------------------------

async function activeMembership(userId: string) {
  return db.query.memberships.findFirst({
    where: and(eq(memberships.userId, userId), sql`${memberships.status} = 'active'`),
    with: { role: true }
  }) ?? null;
}

function buildClaims(userId: string, email: string, membership: { businessId: string; role: { code: string } } | null) {
  const claims: AccessTokenClaims = {
    sub: userId,
    email,
    tenantId: membership?.businessId ?? null,
    role: (membership?.role.code as AccessTokenClaims["role"]) ?? null,
    permissions: [],
    jti: crypto.randomUUID(),
    iat: Math.floor(Date.now() / 1000),
    exp: Math.floor(Date.now() / 1000) + 15 * 60
  };
  return claims;
}

function tokenConfig() {
  return { accessExpiresIn: 15 * 60, refreshExpiresIn: REFRESH_TTL_MS / 1000 };
}

async function finishLogin(
  app: FastifyInstance,
  user: { id: string; email: string; name: string },
  membership: { id: string; businessId: string; role: { code: string } } | null,
  claims: AccessTokenClaims,
  config: { accessExpiresIn: number; refreshExpiresIn: number },
  meta: { ip?: string; ua?: string }
) {
  const refreshToken = issueRefreshToken();
  await createSession({
    userId: user.id,
    businessId: claims.tenantId,
    refreshToken,
    ttlMs: REFRESH_TTL_MS,
    ip: meta.ip ?? null,
    userAgent: meta.ua ?? null
  });

  return {
    user: { id: user.id, email: user.email, name: user.name },
    membership: membership
      ? {
          id: membership.id, businessId: membership.businessId,
          role: membership.role.code as LoginResult["membership"]["role"], status: "active" as const
        }
      : null,
    tokens: {
      accessToken: createAccessToken(app, claims),
      accessExpiresIn: config.accessExpiresIn,
      refreshToken,
      refreshExpiresIn: config.refreshExpiresIn
    }
  };
}
```

```ts
export async function authRoutes(app: FastifyInstance) {
  const auth = issuer(app);

  app.get("/auth/health", async () => ({ ok: true }));

  app.post("/auth/signup", { schema: { body: signupSchema } }, async (req, reply) => {
    const user = await auth.provisionUser(req.body, req.log);
    return reply.code(201).send({ success: true as const, data: { user } });
  });

  app.get("/auth/verify-email", { schema: { querystring: verifyEmailSchema } }, async (req, reply) => {
    await auth.verifyEmail(req.query.token);
    return { success: true as const, data: { verified: true } };
  });

  app.post("/auth/login", { config: { rateLimit: rateLimitOptions(5, "1 minute") } }, async (req, reply) => {
    const body = loginSchema.parse(req.body);
    const result = await auth.login(body, { ip: req.ip, ua: req.headers["user-agent"] });
    return reply.send({ success: true as const, data: result });
  });

  app.post("/auth/refresh", async (req, reply) => {
    // Web sends refresh token in body (BFF); server actions forward it from cookie.
    const body = (req.body ?? {}) as { refreshToken?: string };
    if (!body.refreshToken) throw new ApiError("TOKEN_INVALID", "Missing refresh token");
    const result = await auth.refresh({ refreshToken: body.refreshToken }, { ip: req.ip, ua: req.headers["user-agent"] });
    return reply.send({ success: true as const, data: result });
  });

  app.post("/auth/logout", async (req) => {
    const body = (req.body ?? {}) as { refreshToken?: string };
    if (body.refreshToken) await auth.logout(body.refreshToken);
    return { success: true as const, data: null };
  });

  app.post("/auth/forgot-password", { schema: { body: forgotPasswordSchema } }, async (req) => {
    await auth.forgotPassword(req.body.email, req.log);
    return { success: true as const, data: { sent: true } };
  });

  app.post("/auth/reset-password", { schema: { body: resetPasswordSchema } }, async (req) => {
    await auth.resetPassword(req.body.token, req.body.password);
    return { success: true as const, data: { reset: true } };
  });
}
```

```ts
/**

export const authenticate: FastifyPluginAsync = async (app) => {
```

```ts
export async function createBusinessAndStore(userId: string, businessInput: CreateBusinessInput, storeInput: CreateStoreInput) {
  const role = await db.query.roles.findFirst({ where: eq(roles.code, "owner") });
  if (!role) throw new ApiError("INTERNAL", "Owner role missing — run seeds");
  // Deactivate any pre-existing memberships for the user so the new business is active
  const baseSlug = slugify(businessInput.name);
  const slug = await uniqueBusinessSlug(baseSlug);

  const business = await db.transaction(async (tx) => {
    const [biz] = await tx.insert(businesses).values({
      slug,
      name: businessInput.name,
      type: businessInput.type,
      industry: businessInput.industry,
      phone: businessInput.phone,
      gstin: businessInput.gstin || null,
      pan: businessInput.pan || null,
      addressLine: businessInput.addressLine,
      city: businessInput.city,
      state: businessInput.state,
      pincode: businessInput.pincode,
      email: undefined // set below
    }).returning();

    await tx.insert(stores).values({
      businessId: biz!.id,
      name: storeInput.name,
      slug: await uniqueStoreSlug(storeInput.slug ?? slug),
      tagline: storeInput.tagline || null,
      description: storeInput.description || null
    });

    await tx.insert(memberships).values({
      userId,
      businessId: biz!.id,
      roleId: role.id,
      status: "active"
    });

    return biz!;
  });

  return business;
}
```

**Session strategy (BFF):** the refresh token lives in an httpOnly cookie owned by Next.js. Access token is returned to the browser and held in a Zustand store; the API client attaches it as `Authorization: Bearer` (CSRF-immune for mutations). On `TOKEN_EXPIRED`, the client calls the `refreshSession()` server action which uses the cookie, mints a new access token, and returns it. Blueprint §13.2.

```ts
export const REFRESH_COOKIE = "bs_refresh";

export function getRefreshToken(): string | undefined {
  return cookies().get(REFRESH_COOKIE)?.value;
}

export function setRefreshToken(token: string) {
  cookies().set(REFRESH_COOKIE, token, {
    httpOnly: true,
    sameSite: "lax",
    secure: process.env.NODE_ENV === "production",
    path: "/",
    maxAge: 30 * 24 * 60 * 60 // 30d
  });
}

export function clearRefreshToken() {
  cookies().set(REFRESH_COOKIE, "", { httpOnly: true, sameSite: "lax", path: "/", maxAge: 0 });
}
```

```ts
"use client";

import { useSessionStore } from "./session-store";

export class ApiClientError extends Error {
  code: string;
  fieldErrors?: Record<string, string[]>;

  constructor(code: string, message: string, fieldErrors?: Record<string, string[]>) {
    super(message);
    this.code = code;
    this.fieldErrors = fieldErrors;
  }
}

/**
 * Client-side API call. Uses the in-memory access token; on TOKEN_EXPIRED it
 * calls the refreshSession server action, retries once, then clears session.
 */
export async function apiFetch<T>(path: string, init: RequestInit = {}): Promise<T> {
  const { accessToken, setAccessToken, clear } = useSessionStore.getState();
  const headers = new Headers(init.headers);
  headers.set("Content-Type", "application/json");
  if (accessToken) headers.set("Authorization", `Bearer ${accessToken}`);

  const res = await fetch(path, { ...init, headers });
  const payload = (await res.json().catch(() => ({}))) as
    | { success: true; data: T }
    | { success: false; error: { code: string; message: string; fieldErrors?: Record<string, string[]> } };

  if (!res.ok) {
    if ("success" in payload && !payload.success) {
      if (payload.error.code === "TOKEN_EXPIRED" || payload.error.code === "TOKEN_INVALID") {
        const refreshed = await refreshSessionAction();
        if (refreshed) {
          setAccessToken(refreshed.accessToken);
          return apiFetch<T>(path, init);
        }
        clear();
      }
      throw new ApiClientError(payload.error.code, payload.error.message, payload.error.fieldErrors);
    }
    throw new ApiClientError("INTERNAL", "Unexpected server response");
  }

  if ("error" in payload && !payload.success) throw new ApiClientError(payload.error.code, payload.error.message);
  return payload.data;
}

async function refreshSessionAction(): Promise<{ accessToken: string } | null> {
  const res = await fetch("/api/auth/session", { method: "POST", cache: "no-store" });
  if (!res.ok) return null;
  const payload = await res.json();
  return payload?.data ?? null;
}
```

```ts
"use server";

import { redirect } from "next/navigation";
import { setRefreshToken, clearRefreshToken } from "./cookies";
import type { SessionTokens } from "@bharatstore/shared";

async function callApi<T>(path: string, body: unknown, token?: string): Promise<T> {
  const res = await fetch(`${process.env.API_URL ?? "http://localhost:4000"}${path}`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      ...(token ? { Authorization: `Bearer ${token}` } : {})
    },
    body: JSON.stringify(body)
  });
  const payload = await res.json().catch(() => ({}));
  if (!res.ok) throw new Error(payload?.error?.message ?? "Request failed");
  return payload.data;
}

export async function signupAction(formData: FormData) {
  const [error, result] = await runSafe(() =>
    callApi<{ user: { id: string; email: string } }>("/api/auth/signup", {
      name: formData.get("name"),
      email: formData.get("email"),
      password: formData.get("password")
    })
  );
  return error ?? { ok: true as const, email: result.user.email };
}

export async function loginAction(formData: FormData) {
  const result = await runSafe(() =>
    callApi<{ tokens: SessionTokens; user: { id: string; email: string; name: string } }>("/api/auth/login", {
      email: formData.get("email"),
      password: formData.get("password")
    })
  );
  if ("message" in result) return result;
  setRefreshToken(result.tokens.refreshToken);
  redirect("/dashboard");
}

export async function logoutAction() {
  clearRefreshToken();
  redirect("/login");
}

export async function refreshSessionServerAction(): Promise<{ accessToken: string } | null> {
  const { getRefreshToken } = await import("./cookies");
  const token = getRefreshToken();
  if (!token) return null;
  const result = await runSafe(() =>
    callApi<{ tokens: SessionTokens }>("/api/auth/refresh", { refreshToken: token })
  );
  if ("accessToken" in result) return { accessToken: result.tokens.accessToken };
  clearRefreshToken();
  return null;
}

async function runSafe<T>(fn: () => Promise<T>): Promise<T | { message: string }> {
  try {
    return await fn();
  } catch (e) {
    return { message: e instanceof Error ? e.message : "Something went wrong" };
  }
}
```

```ts
import { NextRequest, NextResponse } from "next/server";

const DASHBOARD_PREFIX = "/dashboard";
const ONBOARDING = "/onboarding";
const AUTH_PAGES = ["/login", "/signup", "/forgot-password"];

export function middleware(req: NextRequest) {
  const { pathname } = req.nextUrl;
  const hasRefresh = Boolean(req.cookies.get("bs_refresh")?.value);

  const isAuthPage = AUTH_PAGES.some((p) => pathname.startsWith(p));
  const isProtected = pathname.startsWith(DASHBOARD_PREFIX) || pathname.startsWith(ONBOARDING);

  if (isProtected && !hasRefresh) {
    const url = req.nextUrl.clone();
    url.pathname = "/login";
    url.searchParams.set("next", pathname);
    return NextResponse.redirect(url);
  }
  if (isAuthPage && hasRefresh) {
    const url = req.nextUrl.clone();
    url.pathname = "/dashboard";
    return NextResponse.redirect(url);
  }
  return NextResponse.next();
}

export const config = { matcher: ["/dashboard/:path*", "/onboarding", "/login", "/signup", "/forgot-password"] };
```

```ts
"use server";

import { redirect } from "next/navigation";
import { refreshSessionServerAction } from "./auth-actions";

export async function onboardBusinessAction(formData: FormData) {
  const session = await refreshSessionServerAction();
  if (!session) return { error: "You need to log in again" };

  const fields = ["name", "type", "industry", "phone", "addressLine", "city", "state", "pincode", "gstin", "pan"] as const;
  const business: Record<string, string> = {};
  for (const k of fields) {
    const v = formData.get(k);
    if (typeof v === "string" && v.trim()) business[k] = v.trim();
  }
  const store = {
    name: String(formData.get("storeName") ?? business.name),
    slug: (formData.get("slug") as string)?.trim() || undefined,
    tagline: (formData.get("tagline") as string)?.trim() || undefined
  };

  const res = await fetch(`${process.env.API_URL ?? "http://localhost:4000"}/api/businesses`, {
    method: "POST",
    headers: { "Content-Type": "application/json", Authorization: `Bearer ${session.accessToken}` },
    body: JSON.stringify({ business, store })
  });
  const payload = await res.json().catch(() => ({}));
  if (!res.ok) return { error: payload?.error?.message ?? "Could not create your business" };

  redirect("/dashboard");
}
```

```ts
describe("auth.flow", () => {

    await app.ready();

  it("provisions a user and hides password hashes", async () => {

    expect(body.data.user).not.toHaveProperty("password_hash");

  it("rejects duplicate emails with EMAIL_TAKEN", async () => {
    const email = unique("dup@example.co");
    await post("/api/auth/signup", { name: "A", email, password: "SecurePass@123" });
    const res = await post("/api/auth/signup", { name: "B", email, password: "SecurePass@123" });
    expect(res.statusCode).toBe(409);
    expect(res.json().error.code).toBe("EMAIL_TAKEN");
  });

  it("logs in, returns tokens, and refresh flow rotates the refresh token", async () => {
    const { email, password, accessToken, refreshToken } = await signupAndLogin("rotate");
    expect(accessToken).toBeTruthy();
    expect(refreshToken).toBeTruthy();

    const me = await get("/api/auth/me", accessToken);
    expect(me.statusCode).toBe(200);
    expect(me.json().data.user.email).toBe(email);
```

```ts
import { describe, expect, it, beforeAll } from "vitest";
import { app, unique, post, get, signupAndLogin } from "./helpers";

describe("tenant.isolation", () => {
  beforeAll(async () => {
    await app.ready();
  });

  async function makeTenant(prefix: string) {
    const { accessToken } = await signupAndLogin(prefix);
    const name = unique(prefix);
    const created = await post(
      "/api/businesses",
      { business: { name, type: "retail", industry: "electronics", phone: "9890000000" }, store: {} },
      accessToken
    );
    expect(created.statusCode).toBe(201);
    return { accessToken, businessId: created.json().data.business.id };
  }

  it("creates a business and assigns the owner member", async () => {
    const { accessToken, businessId } = await makeTenant("iso");
    const me = await get("/api/businesses/me", accessToken);
    expect(me.statusCode).toBe(200);
    expect(me.json().data.business.id).toBe(businessId);
    expect(me.json().data.userRole).toBe("owner");
  });

  it("does not let tenant A read tenant B's business", async () => {
    const a = await makeTenant("isoA");
    const b = await makeTenant("isoB");

    // B tries to read their own business using A's token → expected authorization failure
    const sneaky = await post(
      "/api/businesses/me",
      { businessId: b.businessId },
      a.accessToken
    );
    expect(sneaky.statusCode).toBe(403);

    // Named-slug collision across tenants is impossible (globally unique slugs)
    expect(a.businessId).not.toBe(b.businessId);
  });

  it("enforces RLS row-level visibility for cross-tenant access", async () => {
    const a = await makeTenant("rlA");
    const b = await makeTenant("rlB");
    // Direct row access with the wrong tenant setting fails at the DB layer.
    // Simulated via API: B cannot view A's store slug.
    await post(
      "/api/businesses/store",
      { businessId: a.businessId },
      b.accessToken
    ).then(async (res) => {
      // With RLS, any row filtered out of the caller's tenant returns 403/404
      expect([403, 404]).toContain(res.statusCode);
    });
  });
});
```

> The two last tests encode the isolation contract: the API must reject cross-tenant reads on every authenticated route. During execution, confirm the router returns 403 (not a leak) and note any route that returns 200 — those are the real bugs RLS is gating.
